# ETRI K2026-030 자소서 초안 (2026-09-16)

> 자율주행지능연구실 · 실도로 E2E 자율주행 데이터 가공/분류/검증
> ※ 글자 수는 작년 기준 500자로 가정. 공고 확인 후 조정 필요.

## A안 — 검증 중심 (추천)

실제 자율주행 차량이 수집한 nuScenes CAN 버스 데이터로 실시간 주행 안전성 분석 파이프라인을 구축했습니다. 2Hz에서 950Hz까지 주기가 다른 센서 채널을 10Hz로 통합하면서, 평균만 남기면 급제동 순간이 사라진다는 것을 확인하고 구간 극값을 함께 보존하도록 설계했습니다. 979개 주행 구간 191,089건을 전수 검증해 채널이 통째로 비어 있는 결함 데이터를 찾아냈고, 센서 불일치로 걸린 15건은 실제 고장이 아니라 제가 만든 리샘플링 지연 때문임을 규명해 검증 규칙을 고쳤습니다. 탐지 또한 임계값을 넘은 구간을 세던 방식에서 하나의 기동을 한 건으로 묶는 방식으로 바로잡았습니다. 데이터를 받아 쓰는 데 그치지 않고 의심하고 되짚어온 과정이 실도로 데이터를 가공·분류·검증하는 이번 업무와 그대로 맞닿아 있다고 생각합니다. 군 복무 중 운전병으로 실차량을 운용한 경험은 센서 값과 도로를 함께 읽는 감각으로 남아 있습니다.

## B안 — 가공·분류·검증 3단 균형

실제 자율주행 차량의 nuScenes CAN 버스 데이터로 주행 안전성 분석 파이프라인을 구축하며 데이터를 가공하고 분류하고 검증하는 과정을 모두 다뤘습니다. 가공에서는 2Hz부터 950Hz까지 주기가 다른 센서 채널을 10Hz로 통합하되, 평균만 남기면 급제동 순간이 사라지기에 구간 극값을 함께 보존했습니다. 분류에서는 급제동·급선회·급가속 기준을 차량 동역학에서 인용한 뒤 979개 구간 전체로 선택도를 측정해 보정했고, 하나의 기동이 여러 건으로 세어지던 문제를 사건 단위 탐지로 바로잡았습니다. 검증에서는 191,089건을 전수 점검해 채널이 비어 있는 결함 데이터를 찾아냈고, 불일치로 걸린 15건이 실제 고장이 아님을 규명해 규칙을 고쳤습니다. 군 복무 중 운전병으로 실차량을 운용한 경험은 센서 값과 도로를 함께 읽는 감각으로 남아 있습니다.
